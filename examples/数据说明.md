# 保管流转演练

calendar 是固定偏移时区的营业日历，weekdays 采用周一为 0，营业区间为左闭右开，holidays 为当地日期。records 定义两个案件：closed 经过拒绝再交接后封存，waiting 在观察点仍等待交接。案例身份仅用于本地演练，不含真实证据。

context 通过正式案件、交接和封存接口写入事件，时钟可注入；交接记录关联真实 handoff_id，链校验应通过。它不预计算流程时长或生存统计。

process_demo 在同一份合成记录上运行 `sealvault.process`：closed 经历一次拒绝、再交接后封存，waiting 在观察截止仍等待交接（右删失）。分析只处理流程元数据（动作、角色、handoff_id、时间），不读取证据内容；营业时长按本地日历的工作日、09:00–17:00 营业区间和假日计算，与自然时长并列输出，日历版本 local-1 随快照固定。
